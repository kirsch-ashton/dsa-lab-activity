# Laboratory Activity: Recursion

# Description
This program demonstrates a recursive Binary Search Algorithm. It searches for the target value in a sorted array.

# Programming language used
Java is the programming languageg used for this activity.

# Instructions for compiling/running
Simply download the file(s) and place them in one folder, have an IDE (like Visual Studio Code) with Java installed to compile/run the file.
